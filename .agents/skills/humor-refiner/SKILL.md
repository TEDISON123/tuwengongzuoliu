# 幽默化改造与网感赋能引擎 (Humor Refiner) 🎭

## 1. 技能定位与核心目标
金融知识往往晦涩、冰冷、充满距离感。若只有数据和案例，容易变成枯燥的财经研报。

小红书爆款图文的核心密码是：**“内核极其专业硬核，表达极其轻盈幽默”**。`humor-refiner` 负责在不破坏专业逻辑与「理性讨论」合规底线的前提下，为图文笔记注入高情商吐槽、神级比喻、打工人共鸣自嘲与括号内心戏，让读者在**“会心一笑”**或**“扎心痛感”**中刷完全篇并疯狂在评论区互动。

---

## 2. 四大幽默化修辞技法 (Humor Techniques)

### ① 神级通俗隐喻 (God-tier Metaphors)
- 将复杂的金融术语降维为普通人每天可见的生活场景：
  - *“全额提前还房贷”* ➔ **“给房子装了四道防盗门，结果把自己的钥匙反锁在里面”**；
  - *“买小金豆微量储蓄”* ➔ **“以为在造微型诺亚方舟，其实是在给金店老板众筹年终奖”**；
  - *“追高买入高股息防守资产”* ➔ **“为了防晒，把帐篷搭在了火山口”**。

### ② 当代打工人扎心自嘲 (Relatable Self-Deprecation)
- 直击打工人与新中产的生存现实，引发群体共鸣：
  - *“手握50万闲钱感觉自己能抄底世界，失业三个月发现猫粮都得换成散装”*；
  - *“省了30万纸面利息，但下周被裁员时，银行可不会把利息切成片给你当下酒菜”*。

### ③ 括号内心戏与旁白吐槽 (Parenthetical OS)
- 在严肃论点后增加一行括号反差旁白，制造戏剧冲突：
  - *（银行行长：感谢这位大善人自愿提前结清低息贷款，我们刚好可以放高息消费贷了）*
  - *（黄金回收小哥：火熔枪一响，你的大盘梦碎成了废铁渣）*
  - *（钱包：你高兴就好，反正每次冲动受罪的都是我）*

### ④ 戏谑站队与促评诱饵 (Witty Debate Hooks)
- 在 P6 站队页将严肃的 A/B 选项包装为戏剧化的身份标签：
  - 🔴 选 A【无债一身轻派】：*“哪怕喝粥也睡得踏实，绝不给银行多打一天工！”*
  - 🔵 选 B【现金呼吸机派】：*“手握子弹才有底气，水泥又不能吃，我命由钱不由房！”*

---

## 3. 合规底线与红线禁区 (Compliance Guardrails)

为了百分之百通过小红书官方「理性讨论」审核，幽默改造必须遵守**“三不原则”**：
1. **不搞人身攻击与群体对立**：严禁挑动性别对立、阶层仇恨或地域歧视；
2. **不搞低俗低智与网络脏话**：保持体面高级的幽默感（自嘲与比喻），杜绝烂梗粗鄙用语；
3. **不虚构误导性投资收益**：幽默仅作用于修辞表达，底层的利率、利差、费率数据必须严谨准确。

## 4. 脚本调用与命令行工具

```bash
# 对指定议题执行幽默改造
python3 skills/humor-refiner/scripts/refine_humor.py \
  --topic-id mortgage_vs_invest

# 打印特定议题的幽默金句库
python3 skills/humor-refiner/scripts/refine_humor.py --list-quotes
```
