# 事实案例引擎 (Fact Case Injector) 📜

## 1. 技能定位与核心目标
在小红书金融与理财内容中，纯学术理论与说教容易被读者划走，只有**“真实的人、具体的账本、惨痛或成功的现实切片”**才能真正唤起用户的恐惧、贪婪与共鸣。

`fact-case-injector` 旨在为图文笔记自动注入符合论点逻辑的真实案例切片，支持正反方立论，增强说服力，同时引爆评论区同类经历的互动争鸣。

---

## 2. 四大案例切片类型库 (Case Typology)

### ① 典型中产生活切片 (Middle-Class Financial Realities)
- **特征**：聚焦一二线城市 30~45 岁工薪中产、大厂员工、小企业主的真实收支困境。
- **典型主题**：降薪裁员后的刚性月供断档、手头闲钱理财踩雷、孩子教育支出挤占流动性。
- **作用**：让读者惊呼“这就是在报我的身份证号！”

### ② 极端断供与违约警示 (Extreme Stress-Testing Cases)
- **特征**：资产负债表断裂导致的真实后果（如资产被强制法拍、消费贷以贷养贷崩盘）。
- **作用**：为反方（防守派/留流动性派）提供坚实的事实防御论据。

### ③ 商业机构与消费套路前车之鉴 (Consumer Pitfall & Market Precedents)
- **特征**：金店工艺溢价变现被扣成废铁、某些理财产品纸面高息实则破净清算。
- **作用**：为反收割官、价值投资人提供不可反驳的客观事实支撑。

### ④ 历史长周期对照样本 (Historical Macro Cycles)
- **特征**：日本失去的三十年个人资产配置、上世纪 70 年代大滞胀时期的黄金表现。
- **作用**：为宏观学者视角提供长达数十年的宏大视野与周期参照物。

---

## 3. 案例注入准则与合规边界 (Rules & Compliance)

1. **去敏化与真实感平衡**：严格遵守隐私保护，采用“城市+行业+年龄+金额”的脱敏刻画（如“杭州某大厂35岁前架构师”、“深圳二胎家庭年收入40万”），避免指名道姓。
2. **账本必须精确可信**：案例中必须包含关键财务数字（如月供8300元、闲钱50万、理财收益率1.8%），杜绝模糊的“很多钱”。
3. **保持中立与对立对冲**：不能全篇只有一个案例倾斜于单方观点，必须正反两方各配对应对立案例，符合小红书「理性讨论」双边平衡标准。
4. **微型卡片化适配**：案例文字必须精炼（50~80字内），提炼为卡片中的“【现实切片】”或“【前车之鉴】”专属组件。

## 4. 脚本调用与命令行使用

```bash
# 针对提前还贷议题提取并注入案例
python3 skills/fact-case-injector/scripts/inject_cases.py \
  --topic-id mortgage_vs_invest \
  --viewpoint side_a

# 打印所有主题已入库的事实案例
python3 skills/fact-case-injector/scripts/inject_cases.py --list-all
```
